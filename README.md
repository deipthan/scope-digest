# Scope Digest

GI for the internal medicine resident, in two parts.

- **The Digest** — twenty focused clinical modules (`ugib.html`, `varices.html`, …). Bottom line → red flags → numbered steps → landmark trials. Every recommendation names its guideline.
- **The GI Handbook** — `handbook.html`, a single self-contained page: 76 core topics across 12 chapters, 73 diagrams, 58 trials, score calculators, presentation flashcards and a 109-question self-test.

Static site, no build step. Served by GitHub Pages from `main`: https://deipthan.github.io/scope-digest/

Written and maintained by Deipthan Prabakar, MD. Educational reference for clinicians in training — not medical advice.
